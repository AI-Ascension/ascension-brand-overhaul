Content plan: a full-width illustrated hero introduces Ascension and the existing report/build actions; the dated report supplies the concrete evidence; the existing method and evidence sections explain how to inspect it; the signup section retains the final action.

Target: isolated `brand-website-art`, based on website commit `56e532b21922f39480cd15dcbb465676770408f5`. Canonical source images stay in this brand repository. Website copies must bind exact source paths and hashes; no generated image becomes gameplay evidence.
