# Private audit delivery scope

This local archive and the private `AI-Ascension/ascension-brand-overhaul` repository intentionally retain selected internal execution records: model/effort and native ancestry observations, timestamps, account identity for authorized GitHub operations, and review receipts. These are audit evidence, not public marketing content or provider attestation. The original requested role tree is separate from actual observed ancestry.

No public archive is prepared or approved. A future public projection must remove internal account/thread/operation metadata, receive a fresh content-level privacy review, and bind approval to its exact manifest digest. Approval of this private source audit is not approval to publish private artifacts or change repository visibility.

The source inventory excludes ignored execution directories, credentials by known names, font binaries, dependencies, game assets, symlinks, and special files. Pattern exclusions alone are not a secret scanner. Root and independent reviewers inspect candidate contents. Raw provider error responses and exact machine-specific tool commands stay in ignored private storage; migration plans retain normalized API status diagnostics. Required source/report URLs and public GitHub revisions remain inspectable.

Historical audit findings remain as historical records. Their presence is not a claim that the final candidate still has the same defects; the subsequent review and exact manifest binding establish the final scope.
