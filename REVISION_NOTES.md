# Version 2.0.0 — Astra-authored gpt-image-2 artwork

This version implements the user's September 7, 2026 direction: **all art must be generated with gpt-image-2 from an Astra-agent-authored prompt**.

The new policy replaces—not supplements—the former multi-lane art instructions. Logos, wordmarks, icons, templates, banners, cards, overlays, diagrams, and campaign artwork now use the same mandatory generation path as illustrations. Direct code-drawn SVG/Canvas/Python/CSS art, stock art, manual tracing/repainting, legacy-art substitution, and alternate image models are prohibited.

The three-level agent hierarchy and 49-role catalog remain. W02-C1-BUILD and W02-C2-BUILD are the two Astra/max author leaves. The other 47 roles remain Luna/max. Leads/coordinators do not change models. gpt-image-2 is an image tool, not a fourth-level agent. Missing required model access blocks the affected job without fallback.

The original 80 mapped families remain represented: 72 newly generated artwork families, three authentic evidence-media families, and five preserved reference/archive records. The latest-run poster is now generated editorial artwork, not an authentic-frame substitute. Real evidence media cannot be generated or generatively retouched. Historical assets remain in the archive for rollback/evidence only, not in new-brand artwork.

Raster exports replace former native-vector requirements. Prompts, edit history, original generated outputs, source/reference metadata, and hashes form the reproducible production source package; no native editable-vector or video-generation capability is assumed. Only noncreative crops/resizes/encoding, icon slicing, and assembly of unchanged generated frames are allowed downstream.

The master prompt, role catalog, role prompts, runtime intent/config example, task schema, requirements, art registers, per-asset author briefs, surface map, offline board, source references, validation logic, tests, and integrity records have been revised together. The package now requires per-master native Astra authorship and exact prompt hashes, gpt-image-2 backend evidence, and per-export lineage.

No artwork generation, live Astra/Luna delegation, GitHub changes, deployments, or campaign publication was performed while revising this package. Package/helper tests are not evidence that downstream implementation has occurred.
