# Launch kit

This directory contains a source-linked, report-first launch package. It is a planning artifact, not an operated campaign.

- [First episode script](first-episode.md) has actual-capture-ready and report-only forms, qualified copy variants, and evidence gates.
- [Launch post variants](launch-posts.md) are drafts for review; no channel has been posted.
- [Email digest](email-digest.md) is a consent-aware template; no send or successful delivery is claimed.
- [Profile and press copy](profile-and-press.md) contains bios, pinned introduction, boilerplate, short pitch, milestone language, and correction handling.

The relative calendar and item-level source/asset/rights/measurement fields live in [../calendar.json](../calendar.json). All destinations and art references remain gated until their exact source, rights, deployment, and review checks pass.
