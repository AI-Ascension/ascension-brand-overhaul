# Creator and contributor kit

Status: bounded drafts only. No creator is named, contacted, promised compensation, or presented as a partner. The kit has no contact list and does not scrape or infer private contact data.

- Outreach drafts provide four role-specific messages with one artifact and one bounded request each.
- Creator brief sets access, annotation, disclosure, attribution, and correction boundaries.
- Request template is a fill-in draft for an approved channel.
- Attribution standard keeps source facts, commentary, and support separate.

Use a public contact route supplied by the creator, verify channel rules first, and wait for explicit consent. A sent message, reply, agreement, audience result, or collaboration is unobserved until separately recorded.
